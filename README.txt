Afterpay Admin Portal Simulation for Rise 360

How to use:
1. Host the contents of this folder somewhere that gives you a public HTTPS URL.
2. In Rise 360, add an Embed block.
3. Paste an iframe using the hosted index.html URL, for example:
   <iframe src="https://your-host/path/index.html" width="100%" height="720" style="border:0;"></iframe>

Do not paste the contents of index.html directly into Rise. Rise will display it as text.

For local testing:
- Open index.html in a browser.
